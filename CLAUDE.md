# Czech Business Model Radar

Streamlit-приложение: проверенные в мире модели малого бизнеса и микро-SaaS, оценённые для чешского рынка.
Полное состояние проекта, архитектура, решённые проблемы и следующие шаги: **[SESSION_STATE.md](SESSION_STATE.md)**.
Прочитай его в начале сессии и обнови в конце.

## Правила работы
- Общение с пользователем на русском. Интерфейс по умолчанию русский (есть английский).
- Перед крупной задачей — сначала изучить код и показать план; код писать после подтверждения.
- Маленькие коммиты по подшагам, после каждого — краткий отчёт.
- Базовые записи моделей (`data_loader.py`, `curated_more.py`, `catalog/`) не менять:
  чешские данные и исправления — через оверлей `data/cz_enrichment.json` или проверенный патч.
- Не придумывать факты (конкурентов, URL, цифры). Неизвестное — пустое / `unknown` с пометкой.
- Выведенное правилами помечать (`inferred_fields`), черновое — «to verify».
- API-ключи только из env / secrets.
- Новые строки данных переводить: `python scripts/i18n_extract.py`, тест упадёт при пропусках.
