# Проект 1. Проверка оригиналов: работают ли они уже в Чехии

*Выжимка на 2026-09-28 из проекта «Czech Business Model Radar». Вставьте этот текст в новый чат целиком.*

## Контекст

- Репозиторий: `github.com/awr194/epmty`, ветка `main-t24jug`. Локально проект лежит в
  `D:\Downloads\AI folder\Claude projects\Czech-biz-radar` (Windows, `.venv`).
- Приложение на Streamlit: 500 проверенных в мире моделей малого бизнеса и микро-SaaS, оценённых для Чехии.
- У каждой модели есть поле `original_available_in_cz`: продаёт ли оригинал (продукт-прототип) уже в Чехии.
  Статус «yes» снимает 6 баллов с чешского скора (слайдер в сайдбаре). Статус «unknown» не штрафуется.
- Правила проекта: чешские данные и исправления записываются только через оверлей `data/cz_enrichment.json`,
  факты не выдумываются, неизвестное остаётся `unknown`. Статус «no» ставится только вручную, с источником.

## Как устроена проверка

- `market/original_cz.py` ищет признаки на сайте оригинала:
  - **сильные** (статус «yes»): редирект на `.cz`; `hreflang="cs"` в HTML или в HTTP-заголовке `Link`;
    ссылка на собственный `.cz`-домен бренда; `<html lang="cs">`; `og:locale cs_CZ`; «Čeština» в
    переключателе языков; редирект на чешскую версию (`cz.` / `/cs/`, но не `/cs/en.html`); путь
    `/cs/`, `/cs-cz/` или `/cz/`, который открылся, остался на этом пути и сам помечен как чешский;
  - **слабый** (статус «likely»): цены в Kč / CZK, с учётом регистра;
  - строка «Czech Republic» игнорируется, потому что в выпадающих списках стран она есть везде.
- `scripts/check_original_cz.py` учитывает `robots.txt`, делает паузу 1 с и продолжает с места остановки.
  Режимы: `--recheck-unknown`, `--reclassify` (без сети), `--only <имя>`, `--refresh`.
- Результат лежит в `data/original_cz.json`, отчёт в `reports/original_cz_unknown.md` с разделами
  «не прочитан», «нет признаков» и «редирект на другой домен».
- Ручная отметка в оверлее важнее проверки: в `data/cz_enrichment.json` записываются
  `original_available_in_cz` и `original_cz_source`.

## Текущее состояние (прогоны пользователя 26–27.09.2026)

- **«yes» — 30** (например, Canva, Pipedrive, Vinted, Refurbed, Fresha, Shopify, Huel, FareHarbor).
  Архетип Shopify-приложения вручную переведён в «unknown»: его URL ведёт на поиск в App Store.
- **«unknown» — 470**, из них:
  - **44 сайта не прочитаны**: 403 ×25, запрет в robots.txt ×8, нет URL ×4, 429 ×3, SSL ×2, 525 ×1, 401 ×1;
  - **426 прочитаны, но признаков нет.** Часть из них, вероятно, с чешской версией, где язык выбирается
    скриптом в браузере (например, Booksy сразу уходит на `/en-us/`). Но многие (сервисы из России, Индии,
    Бразилии, США) в Чехии действительно не работают.
- **15 сайтов перекидывают на другой домен** (ребрендинги и поглощения: Hotjar → Contentsquare,
  TaxScouts → Taxfix, Fat Llama → Hygglo, VWO → Wingify и др.). **La Belle Assiette** ведёт на
  посторонний сайт, вероятно, домен мёртвый. URL в данных не менялись: это делается только проверенным патчем.

## Что сделать (план)

1. **429 / 525 (4 сайта):** повторить позже с паузой побольше.
2. **Ошибки SSL (2):** попробовать вариант адреса с `www` / без `www`. Проверку сертификата не отключать.
3. **403 (25):** защиту от ботов не обходить (не притворяться браузером). Взять последнюю копию страницы
   из **Wayback Machine** (archive.org, API проверки наличия копии) и записать дату копии как дату факта.
4. **robots.txt запрещает (8):** уважать запрет, архив не использовать, только ручная проверка.
5. **Нет URL (4):** это архетипы без продукта, пометить «неприменимо».
6. **426 без признаков:** добавить чтение **`sitemap.xml`** (адрес в `robots.txt`) и искать там
   `/cs/`, `/cz/` и `hreflang="cs"` (`xhtml:link`).
7. **15 редиректов:** подготовить проверенный патч URL (`patches/`, `scripts/apply_data_patch.py`,
   сначала пробный прогон).
8. После доработки: `python scripts/check_original_cz.py --recheck-unknown`, затем `--reclassify`,
   закоммитить `data/original_cz.json`.

**Приоритет:** для выбора бизнеса этот признак нужен только финалистам. Остальные 470 моделей — улучшение
данных, срочности нет.

## Подводные камни

- В облачной сессии Claude сеть к сайтам закрыта (403 от прокси): проверку сайтов запускает пользователь локально.
- `git pull` не проходит, если локально лежат неотслеживаемые файлы, которые в ветке уже закоммичены
  (`data/original_cz.json`, `reports/*.md`). Их нужно переименовать или удалить перед `pull`.
- Регэксп цены однажды зависал на минифицированном JS. Сейчас он ограничен, и есть тест на скорость.
