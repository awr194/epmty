## 1. Отчёты Sklik + Google Ads для агентств

**Суть.** Автоматический ежемесячный отчёт клиенту агентства или PPC-фрилансера: Sklik и Google Ads
в одном чешском отчёте (PDF/ссылка), без ручного сведения таблиц.

**Почему подходит.** Sklik — чешская рекламная система, глобальные сервисы отчётности поддерживают её
слабо или никак (проверить). Клиенты — B2B, мало, платят регулярно: 46 клиентов по 990 CZK.
Родной чешский нужен и для продаж, и для текста отчётов.

**Главные риски.** Бесплатный заменитель: коннектор Sklik от Seznam для Looker Studio (open source на
GitHub) и самодельные связки через Make / Keboola / BigQuery. Ценность должна быть «готовый отчёт по клику
без настройки Looker Studio». Доступ к API Sklik и его условия — проверить; время на поддержку.

**No-code путь (проверить).** Looker Studio / Google Sheets + коннектор или Make, шаблон отчёта,
оплата через Fakturoid / QR platba.

## 3. Автоматические запросы отзывов

**Суть.** После визита или заказа клиент получает SMS/e-mail с просьбой оставить отзыв на Google и
Firmy.cz; недовольных — сначала на внутреннюю форму.

**Почему подходит.** Понятная ценность для парикмахерских, автосервисов, стоматологий, кафе; легко
собрать на no-code; B2B, 54 клиента по 849 CZK. Чешский — для продаж по телефону и текстов.

**Конкуренты.** Ratemat.cz — почти прямой клон NiceJob (SMS/e-mail, виджеты, ответы на отзывы);
Walio.cz — через карты лояльности в Wallet. Шанс — узкий сегмент, который они не обслуживают
(например, pneuservisy / автосервисы в регионах) — выяснить на интервью.

**Главные риски.** Правила Google и Seznam к «выпрашиванию» отзывов (фильтрация недовольных может
нарушать правила — проверить); согласие на рассылку по GDPR и закону 480/2004 Sb.; конкуренция
модулей в системах бронирования.

**No-code путь (проверить).** Make/Zapier + SMS-шлюз (например, BulkGate или GoSMS — проверить цены)
+ простая форма.

## (снято) AI-описания товаров для e-shop'ов

**Суть.** Генерация чешских описаний и SEO-текстов для каталога (Shoptet, Upgates) пачками, с
импортом обратно в магазин.

**Почему подходит.** Качество чешского текста — ваше преимущество; техника простая (LLM API + CSV);
B2B, 70 клиентов по 649 CZK.

**Почему снято.** В маркетплейсе Shoptet Doplňky уже есть дополнение в один клик (AI Copywriter by
JARABOT), плюс GPTfeed и Editee, плюс сам ChatGPT как бесплатный заменитель. Продавать отдельный SaaS
мимо Shoptet Doplňky тяжело.

## 2. Подготовка к экзамену по чешскому для иностранцев (был резервом)

Сильное совпадение с профилем (родной чешский). Экзамен по чешскому уровня A2 нужен для постоянного
пребывания, B1 — для гражданства (требования проверить на cestina-pro-cizince.cz). Это маркетплейс:
нужно одновременно найти преподавателей и студентов — тяжелее при работе по вечерам; вариант проще —
начать как собственный онлайн-курс / пробные тесты, без маркетплейса. Конкуренты не исследованы —
следующий шаг исследования.

## Шаг 5: интервью (1–2 недели)

По каждому финалисту 5–10 разговоров с потенциальными клиентами. Цель — не продать, а узнать.

**Кого искать**
1. Sklik-отчёты: PPC-фрилансеры и малые агентства (LinkedIn, чешские Facebook-группы про PPC,
   список партнёров Sklik — проверить, есть ли публичный).
2. Отзывы: владельцы салонов, автосервисов, стоматологий рядом с вами (лично или по телефону).
3. Экзамен по чешскому: иностранцы в Чехии (группы экспатов в Facebook, Expats.cz, языковые школы).
4. Отзывы (если оставляем): автосервисы, pneuservisy, стоматологии — спросить, знают ли Ratemat.

**Вопросы (одинаковые для всех)**
1. Как вы сейчас решаете [задачу]? Покажите, пожалуйста.
2. Сколько времени / денег это занимает в месяц?
3. Что в этом раздражает больше всего?
4. Пробовали ли готовые сервисы? Почему бросили / почему не пробовали?
5. Когда последний раз эта проблема стоила вам клиента или денег?
6. Если бы это решалось за [цена] CZK в месяц — кто у вас принимает решение о покупке?

**Сигнал «да»:** 3 из 10 готовы оставить контакт для пилота или предоплату; проблема повторяется
каждый месяц; сейчас решается вручную или неудобно.
**Сигнал «нет»:** «интересно, но…», решают бесплатно и довольны, покупает не собеседник.

После интервью: одна идея → лендинг на чешском + 3 пилотных клиента за 14 дней
(план в разборе «Разбор для Чехии» в приложении).
